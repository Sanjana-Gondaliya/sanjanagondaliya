# Sanjana Gondaliya — Portfolio

Personal portfolio website for **Sanjana Gondaliya**, UI/UX Designer based in India.

A fast, single-page site with a fixed dark sidebar, animated starfield background,
scroll-reveal animations, animated stat counters, and a live clock.

## Structure

```
.
├── index.html              # Markup
├── assets/
│   ├── css/style.css       # Dark sidebar theme + animations
│   ├── js/main.js          # Starfield, scroll reveals, nav, counters
│   └── img/                # Image assets
└── README.md
```

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8000
# then visit http://localhost:8000
```
